# T5 CRM

Order management for IQS: website and chat orders, calls, courier booking, packaging, delivery, returns,
points and reports. Laravel 12. Staging: https://iqs.top5way.com

Start with `docs/SYSTEM_MAP.md`: every module, the one place each job is done, and the team rules.
